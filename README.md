# 🚀 Nexta Solutions  
### Modern Digital Marketing Agency Landing Page

A fully responsive, dark-themed digital marketing agency website built using **HTML, CSS, and JavaScript**.

This project focuses on strong visual hierarchy, conversion-driven layout, and modern UI design principles.

---

## 🌐 Live Demo

🔗 https://nextasolution.netlify.app  

---

## 📌 Project Overview

Nexta Solutions is a professional agency-style landing page designed to showcase:

- High-impact services
- Case studies with performance metrics
- Conversion-focused CTAs
- Lead capture form
- Modern dark UI design

This project was built as **Day 2 of my 15 Days – 15 New Things challenge**.

---

## ✨ Features

✔ Clean Hero Section with bold typography
