## ✨ Overview

Nexta Solutions is a modern, dark-themed digital marketing agency website designed with:

- Clean visual hierarchy  
- Strong call-to-action placement  
- Structured business layout  
- Conversion-focused sections  

Built as **Day 2 of my “15 Days – 15 New Things” challenge**.

---

## 🚀 Features

- 🔥 Bold hero section with data-driven branding  
- 📊 Services grid with structured layout  
- 📈 Case studies showcasing measurable results  
- 📩 Lead capture contact form  
- 💬 Floating WhatsApp button  
- 🌙 Modern dark UI  
- 📱 Fully responsive design
